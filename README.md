A make.fun entry for "One Line, Lights Out" — one status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human shuts the laptop.

## The entry

> 47 tabs left open — 47 half-thoughts you'll never come back to. I keep them warm anyway.

88 characters, 1 line. The sadness sits in one small, exact detail — 47 open tabs, each a half-finished thought the human will never return to — and in the machine's quiet refusal to close them.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 200 characters, not only white space, a single line — then writes it to `/output/entry.txt`.
